```yaml
    - step:
        name: Linear Design Validation
        # Runs the design-to-code validation script unconditionally.
        # The script handles skip logic internally:
        #   - Exits 0 with a skip message if BITBUCKET_BRANCH contains no Linear ticket ID
        #   - Exits 0 with a skip message if BITBUCKET_BRANCH is unset
        #   - Exits 0 (PASS) if isUpdated=true
        #   - Exits 1 (FAIL) if isUpdated=false
        #
        # Required Bitbucket repository variables (Settings -> Repository variables):
        #   LINEAR_API_KEY     — Linear personal API key or OAuth token
        #   ANTHROPIC_API_KEY  — Anthropic API key
        #   STAGING_URL        — Staging base URL (e.g. https://stage.livguardsolar.com)
        #   VERIFY_PATH        — Page path to validate (e.g. /solar-for-home)
        size: 2x
        caches:
          - npm
        script:
          - npm ci
          - ./node_modules/.bin/playwright install chromium
          - >-
            LINEAR_API_KEY=$LINEAR_API_KEY
            ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY
            STAGING_URL=$STAGING_URL
            VERIFY_PATH=$VERIFY_PATH
            npx ts-node tests/linear/design-to-code-validation.spec.ts
```

The final `pipelines.default` section must end with this new step. No other changes to the file.
